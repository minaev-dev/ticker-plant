# Архитектура `ticker-plant` (черновик на 1 страницу, Этап 0)

## Слои системы
1. **Слой данных и разбора (`include/ticker_plant/`, `src/`):**
   - Представление биржевого сообщения (`Message`), коды событий и разбор строк/потоков LOBSTER.
   - Целочисленное хранение цен и объёмов внутри ядра во избежание погрешностей `double` на этапах учёта и обновления стакана.
2. **Слой книги заявок (`OrderBook`):**
   - Поддержание сторон `Bid` (покупка) и `Ask` (продажа), обновление уровней и удаление уровней с нулевым объёмом.
3. **Слой метрик и аналитики:**
   - Вычисление спреда, дисбаланса объёмов и микропрайса поверх текущего состояния стакана.
4. **Слой проверки и производительности (`tests/`, `bench/`):**
   - Юнит-тесты (`GoogleTest` + `ctest`) для контрактов и краевых случаев.
   - Бенчмарки для сопоставления структур данных и схем хранения по времени и памяти.

## Поток данных
Входной поток событий (файл/строки LOBSTER) $\rightarrow$ парсер и валидация $\rightarrow$ обновление `OrderBook` $\rightarrow$ расчёт метрик микроструктуры / тесты / бенчмарки.
